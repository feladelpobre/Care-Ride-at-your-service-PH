# 2-Minute Demo Script (record with Loom, OBS or the phone screen recorder)

**Before recording:** open the live URL in an incognito window; zoom the browser to 110%.

| Time | Show | Say (suggested) |
|---|---|---|
| 0:00–0:15 | Home page | "This is CareRide PH. 82% of wheelchair users in a PGH study said accessibility is their biggest barrier to hospital visits. CareRide lets a caregiver book a safe ride by describing the trip in one message." |
| 0:15–0:40 | Click **Try example 1**, then **Plan my ride** | "I'll type it the way a Filipino family would text, in Taglish. The AI, through the Vercel AI SDK and OpenAI, turns it into structured data: wheelchair, must stay seated, 3rd floor with no elevator, dialysis at 9am." |
| 0:40–1:05 | Review card: vehicle, crew, pickup time; open "How we calculated" | "The safety decisions aren't left to the AI. Tested rules choose a wheelchair van, 2 crew for the stairs, and work back a pickup time from the appointment." |
| 1:05–1:30 | Price section: the distance band, change km, tick **hospital companion** | "The price is estimated from Pasig to St. Luke's BGC using distance bands. If no hospital is named, it prices to the nearest one. I can add a hospital companion who stays until dialysis is done, and the total updates instantly." |
| 1:30–1:45 | Type "Tatay has chest pain" → Plan | "Safety first: emergency words are caught *before* the AI, and we show Call 911 instead of booking." |
| 1:45–2:00 | Confirm a booking → open **Dispatcher** | "Confirmed requests go to the dispatcher board with a driver brief. The repo has GitHub Actions CI with tests and a secret scan, and it deploys on Vercel. Thank you!" |
